# SLL的实现（带头节点）

## main函数测试流程

1. 声明一个单链表 L，初始化，打印状态

2. 输入姓名缩写+学号，尾插法建立链表，遍历，打印状态

3. 3 次按位序取值

4. 3 次按值查找

5. 2 次插入

6. 2 次删除

7. 2 次弱化位序的按值查找

8. 2 次弱化位序的按位查找

9. 置空，打印状态，输入一个字符插入位序1，验证置空后链表仍可使用，遍历

10. 再次置空，用同一字符串头插法重建链表，遍历

11. 销毁链表
